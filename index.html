An OS where software obeys intent

A custom init replaces systemd. The shell talks. The agent runs tools, remembers, browses, and acts — all locally.

🤖

Agent shell

Multi-turn LLM with tool use: memory, notes, alarms, web search, page reading. Tools can create new tools.

🧠

On-device AI

Qwen2.5-1.5B via llama-server inside the guest. RAG-injected memory. Works offline. Your prompts never leave the machine.

🌐

Browser automation

Chromium kiosk + CDP: the agent navigates, clicks, fills forms — using your logged-in sessions, which persist across reboots.

⚡

Lightning receive

Full LNURL-pay: lightning address → BOLT11 invoice. zap 100. Tip links on public shares.

🛰️

Nostr-native

Pure BIP340 Schnorr signing. Posts accepted by live relays — verified, fetchable by anyone.

🛍️

Apps & Store

Turn any site into a home-screen app backed by its session. Browse the F-Droid catalogue, pull APKs to your inbox.

🪐 AgentoNet — your device is the server

Content never leaves your hands. A relay is a blind pipe. The index stores metadata, never files. Three sharing modes, one link format.

🌐

Public

Content-addressed links (sha256 CIDs), discoverable in the DHT index. Anyone with the link fetches from your device through the relay.

🎟️

Restricted

Per-person tokens with expiry and download caps. "Share with Rahul until Friday, max 3 downloads." Revocable anytime.

🔐

Private

E2E via libsodium sealed boxes (X25519 + XSalsa20-Poly1305). Only the recipient's key can open. The relay sees ciphertext.

Verified end-to-end: two independent devices discovered each other via DHT and transferred content through the relay.

Boot it in 3 commands

Requires qemu-system-aarch64 (brew install qemu). macOS gets HVF acceleration automatically.

# 1. download the text bundle from releases
unzip agentic-os-0.3.0-beta-text.zip -d agentic-os && cd agentic-os
# 2. fetch the model (Apache-2.0) + build the model disk
./download-model.sh
# 3. boot — the agent is your shell
./test-interactive.sh

Inside: !net diagnostics · search · netsearch · open <link> · zap 100 · help
